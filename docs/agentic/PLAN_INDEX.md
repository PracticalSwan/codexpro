## Execution rule
Plans 12-21 were explicitly authorized as one cumulative batch and executed on the dedicated `roadmap/plans-12-21` worktree/branch. Plans 12-17 and 20 are verified; Plan 18 Stage 1 is verified while interactive approvals remain capability-gated; Plan 19 is blocked by the current MCP/ChatGPT Tasks capability gate; Plan 21 Stage A is live-verified on Windows while Linux-host validation remains pending and Goals stay host-only. The cumulative build/smoke/stress/audit/release-pack/diff gate passed on 2026-09-07. Each subsystem retains its independent acceptance criteria and status above.

A running CodexPro runtime must remain untouched unless the user separately approves stopping it for a required operation. Agents may never start or restart CodexPro; after an approved stop it must remain stopped. The unified plan defines how to defer global reinstall when this runtime boundary prevents it.

Plans 22–28 are planning-only and are controlled by [the deadline-resilience execution plan](../superpowers/plans/2026-09-08-deadline-resilience-execution.md). Their exact synchronous budget is 1,200,000 ms (20 minutes), but this is explicitly a transport boundary: implementation must preserve full task scope, acceptance criteria, review depth, and required verification by yielding to resumable processes/jobs/Goals/batches instead of rushing.

## Recommended next implementation sequence
Current residual capability work remains `18 → 19 → 21` as external/platform gates allow. The new deadline-resilience program, if separately authorized, should execute as `22 → 23 → 24 → 25 → 26 → 27 → 28`.

Within the deadline-resilience program, Plan 22 establishes the shared contract; Plan 23 fixes composite synchronous verification; Plan 24 creates the structured durable job substrate; Plan 25 puts long verification on that substrate; Plan 26 teaches execution routing without lowering quality; Plan 27 adds explicit resumability to expensive non-process work; and Plan 28 integrates diagnostics/telemetry last so it reports the final canonical state.
